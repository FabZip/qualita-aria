# Qualità dell'aria

PWA mobile per esplorare e confrontare la qualità dell'aria nel tempo.

## v0.1.0

- interfaccia mobile-first
- mappa MapLibre centrata su Roma
- selezione fonte, inquinante, anno e mese
- modalità Mappa, Confronto e Differenza
- dataset dimostrativo locale (non reale)
- manifest e service worker PWA
- versionamento separato app/dataset
- workflow GitHub Pages

> I valori presenti in `data/rome-demo.json` sono sintetici e servono solo allo sviluppo dell'interfaccia. Non vanno interpretati come misure reali.

## Sorgenti previste

EEA, CAMS e OpenAQ. Le integrazioni reali verranno aggiunte mantenendo un formato interno normalizzato.
